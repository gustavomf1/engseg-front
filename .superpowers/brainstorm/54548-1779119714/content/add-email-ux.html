Como o usuário escolhe o tipo do email manual?

Ao adicionar um email manualmente, precisa indicar se vai para Dinâmico (sempre enviado) ou Padrão (desmarcável). Qual abordagem faz mais sentido?

A — Segmented control

Toggle entre "Dinâmico" e "Padrão" antes de clicar em Adicionar. Simples, mas requer que o usuário note o toggle antes de clicar.

Como Dinâmico (sempre)
Como Padrão (desmarcável)

B — Split button com dropdown

Botão "Adicionar" + seta que abre menu com as duas opções. Familiar para quem usa ferramentas como GitHub/Linear. Um pouco mais clique.

Padrão (desmarcável)

C — Radio pills abaixo do input

Dois radio buttons visíveis com rótulo explicativo. Mais legível e explícito — ninguém precisa descobrir o dropdown.
